# Changelog

## Unreleased

### Added

- **The agenda card.** One day's events from several calendars, in the look of
  the Atomic Calendar Revive event list. `days_ahead` picks the day and
  `hide_duplicates` shows an event in several calendars once.
- **Timetables on separate lines.** A description like
  `07:50 Deutsch 09:50 Mathe` shows one entry per line, the times in a column.
